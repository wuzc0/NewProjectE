# ProjectE — Fabric 26.3 移植版

**中文** | [English](README.en.md)

**当前版本：`1.0.2-release`**

基于提供的 Minecraft **26.1.2 Fabric** 版 ProjectE（等价交换）JAR，移植到 **Minecraft 26.3 Fabric**，并持续修复 EMC、自动化、物品交互和兼容性问题。

这是**非官方移植与修复工程**，不是 ProjectE 上游的官方发布。本次发布沿用此前修复，仅将版本标签统一为 `1.0.2-release`。


## 运行环境

| 依赖 | 要求 |
| --- | --- |
| Minecraft Java Edition | 26.3 |
| 模组加载器 | Fabric Loader 0.19.5 或更新的兼容版本 |
| Fabric API | 0.163.0+26.3 或更新的兼容版本 |
| Java | 25 或更高版本 |

不适用于 Forge / NeoForge。联机时，客户端与服务端均需安装相同版本。

## 安装与升级

1. 备份存档及 `config/projecte/`。
2. 安装上述 Fabric 环境和 Fabric API。
3. 从实例的 `mods` 目录移除旧版 ProjectE，放入 `projecte-1.0.2-release-fabric-26.3.jar`。不要同时加载多个版本。
4. 完整重启游戏和服务器，不要仅执行 `/reload`。

沿用 `projecte` 模组 ID 及原有物品、方块 ID。无需清空存档、已学习物品、EMC 配置或玩家余额；不追溯补偿此前损失的 EMC 或已消耗的物品。

## 主要修复与功能

- **兑换扣费**：Shift + 左键兑换只扣除实际插入背包的物品所需 EMC；满背包不扣费，部分空间按实际数量扣费。
- **自动化**：能量收集器可向相邻能量凝聚器供能；凝聚器 MK1 / MK2 支持漏斗进料、产物输出和事务回滚，目标图标同步正常。
- **方块掉落**：补充 22 种模组方块的掉落表和相关挖掘标签；凝聚器拆除时掉落库存，仍需遵守工具和游戏模式规则。
- **暗物质基座**：支持空手右键激活/停用；修复时间洪流怀表读取并加速已加载方块实体的逻辑，保留黑名单和原配置。
- **宝石头盔**：夜视为 20 秒，每 tick 补回时长；正常 20 TPS 下刷新间隔为 0.05 秒。不缩短已有更长或无限夜视。
- **红物质工具**：补齐拳剑穿甲攻击所需的伤害类型，修复钉头锤高/宽/深三连挖掘。不将三连模式改成 3×3。
- **合成催化物**：贤者之石和零度指环参与合成后返还自身，保留充能、EMC、自定义名称等组件。
- **密度宝石与虚空指环**：支持在玩家背包和炼金术箱内转换符合名单的原料，包括高于或等于目标单价的原料；余数保留在缓存中。保护目标同类产物及转换器自身，避免循环回收。
- **库存与组件**：修复部分带 EMC 物品无法移动、丢弃或放入容器后回弹的问题，以及带组件原料被误判为无 EMC 的问题。
- **EMC 指令**：修复自定义值保存、重载、取整覆盖及缓存失效；新增只读转换诊断指令。

## EMC 规则

### 禁价物品

以下物品**没有 EMC**，不能被凝聚器、密度宝石或虚空指环作为 EMC 原料消耗，即使加入转换白名单或设置自定义价格也不能绕过：

- 实际带附魔的物品，包括诅咒和有存储附魔的附魔书。
- 已损耗耐久的物品：损伤值大于 0 即生效，哪怕只掉 1 点耐久。

不删除物品、不移除附魔、不修改耐久，也不扣已有玩家余额。修满耐久且去掉全部实际附魔后，恢复正常计价。空附魔组件或仅有视觉闪光不视为实际附魔。

### 默认价格

除下述范围外，沿用基础移植版的默认定价和取整规则，不进行全物品配方重算：

| 物品/规则 | 默认 EMC |
| --- | --- |
| 铁锭 / 铁块 | 256 / 2304 |
| 金锭 / 金块 | 2048 / 18432 |
| 远古残骸 / 下界合金碎片 | 8192 / 8192 |
| 下界合金锭 / 下界合金块 | 40960 / 368640 |

- 只对具有严格反向配方的同种原料压缩块按原料 EMC 修正，例如 9 铁锭 ↔ 1 铁块；**粒 ↔ 锭暂不调整**。
- 原版下界合金锻造装备按对应基础装备、合金锭和消耗的模板计价。
- 数据包、自定义 EMC 和映射配置会影响实际结果；禁价规则优先。

例如，在上述默认价格下，1 铁块可转为 9 铁锭，1 钻石可转为 4 金锭。目标必须有 EMC，原料必须符合黑白名单；非堆叠原料仍需明确加入白名单。

## 操作与指令

默认键位沿用基础附件，可在游戏设置中修改：

| 操作 | 默认按键 |
| --- | --- |
| 充能 / 降低充能 | `V` / `Shift + V` |
| 切换模式 | `G` |
| 额外功能（例如拳剑范围攻击） | `C` |
| 发射投射物 | `R` |

拳剑需先充能并等待攻击冷却，切换模式不会自动杀怪。基座放入功能物品后，空手右键切换激活状态。

有相应权限的玩家可使用：

```text
/projecte setemc 12345 minecraft:iron_sword
/projecte reloademc
/projecte resetemc minecraft:iron_sword
/projecte removeemc minecraft:iron_sword
/projecte densitydebug
```

- `setemc` 设置自定义值；省略物品参数时使用手持物品。随后执行 `reloademc` 生效。
- `resetemc` 删除自定义覆盖、恢复默认；`removeemc` 是移除该物品的 EMC，而不是恢复默认。两者均需随后重载 EMC。
- 原版 `/reload` 不替代 `/projecte reloademc`。
- `densitydebug` 只读检查玩家背包；对准炼金术箱时检查箱内宝石/指环。显示启用状态、目标价格、缓存和过滤原因，同时写入日志，不修改物品或余额。

普通箱子只存储物品，不运行指环效果；炼金术箱支持漏斗。已启用的功能物品不会被自动抽走，停用后可以抽取，手动取出不受限制。

## 源码与构建

GitHub 精简源码包仅保留**发布用 Java 覆写代码、必要构建脚本、双语文档及指定输入 JAR**。它不是原作者的完整 Gradle 工程；构建脚本面向 Windows，不需要 Gradle。

不包含隔离回归测试、客户端启动测试、测试启动器、链接审计工具、开发历史文档、日志、测试存档或下载的依赖。本地开发环境仍保留这些验证工具，但它们不随此源码包发布。

```text
src/                 发布用修复与适配代码
PortBinary.java      原 JAR 的字节码兼容处理
original.jar         必需的指定 26.1.2 Fabric 构建输入
prepare.py           下载构建依赖
build.py             编译发布代码
package.py           打包运行代码与生成资源
rebuild.py           一键生成发布 JAR，不运行测试
README.md            中文说明
README.en.md         English documentation
.gitignore           排除依赖和生成文件
```

需要 Python 3.10+ 和 JDK 25。首次构建需要联网下载 Mojang、Fabric 和 Maven 依赖。在解压后的源码根目录执行：

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-25'
python rebuild.py
```

发布产物位于当前目录：

```text
projecte-1.0.2-release-fabric-26.3.jar
```

已有完整 `deps/` 缓存时，可执行 `python rebuild.py --offline`，跳过依赖准备。直接运行 `python package.py` 只负责打包，需要先完成适配和编译。

`original.jar` 是继承未覆写功能和原资源所必需的输入，不是测试依赖；SHA-256 必须为：

```text
855e48329f788fd7039d506620c54eec88ad8e4c3d71f209ede41b1aac4b8257
```

上传 GitHub 时，使用交付源码 ZIP 解压后根目录中的文件。`.gitignore` 会排除本机依赖、编译产物和日志，但保留必需的 `original.jar`。将生成的发布 JAR 作为 GitHub Release 附件上传即可。

## 验证与问题反馈

当前代码已通过 **1506 项隔离回归检查**及独立客户端资源加载、主菜单渲染检查。测试使用 Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.163.0+26.3 和 Java 25。

这不等于在所有整合包、完整存档和联机环境中实测。历史测试曾出现原生客户端进程异常，不能保证所有显卡、驱动和第三方模组组合稳定；`release` 是本次版本标签，不代表上游官方认证。

提交问题时请附上游戏/加载器/API/Java 版本、模组列表、复现步骤、最新 `latest.log` 或崩溃报告。转换问题请同时附 `/projecte densitydebug` 输出；请先移除日志中的敏感信息。
